# Amr TV Home

A clean, ad-free home screen for Samsung Tizen TVs, packaged as a TizenBrew app module.

- Clock, date and Dubai weather (Open-Meteo)
- Favourites row and all installed apps
- Opens TizenTube (YouTube without ads) when it is installed in TizenBrew

## Remote controls
- Arrows: move
- OK: open
- Red: add to / remove from favourites
- Green / Yellow: move a favourite left / right
- Back: hide

## Install
In TizenBrew > Module Manager > Add module, type: `gh/<your-github-username>/amr-tv-home`
